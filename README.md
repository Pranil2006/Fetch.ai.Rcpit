# SPython – Machine Learning Workshop

## About

SPython was a 4-day workshop organized by **Fetch.ai** on **Machine Learning and Artificial Intelligence using Python**.

During the workshop, we learned the basics of Machine Learning and worked on practical coding activities. The workshop helped us understand how data is processed and how machine learning models are created and evaluated.

## Topics Covered

- Python Basics
- Introduction to Machine Learning
- Data Preprocessing
- Data Analysis
- Supervised Learning
- Unsupervised Learning
- Model Training
- Model Testing and Evaluation
- Basic Machine Learning Projects

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Learning Outcomes

Through this workshop, I gained practical knowledge of Machine Learning and improved my Python programming and problem-solving skills. I also learned how to work with datasets and build basic machine learning models.
